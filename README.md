## Vercel 배포

### 1. 올리기

```bash
npx vercel
```

Framework Preset **Other**, Build Command·Output Directory **비워둠**.
`api/` 는 Vercel이 자동으로 함수로 잡고 `@vercel/blob` 도 알아서 설치합니다.

### 2. 저장소 연결 — 이걸 해야 수정이 서버에 남습니다

Storage → **Create Database** → **Blob** → Create → Deployments 에서 **Redeploy**

안 하면 수정이 **각자 브라우저에만** 저장됩니다. 화면 상단 배지로 확인:
`서버 저장 · 팀 공유`(녹색) / `이 브라우저에만 저장됨`(빨강)

점검: 배포 주소 뒤 `/api/store` → `{"overrides":{},...}` 나오면 정상

### 3. 접근 제한 — 권장

Settings → Deployment Protection → **Vercel Authentication**
단가는 대외비인데 기본값은 링크만 알면 누구나 열립니다.
