## 가격 검색 (`/`)

| 품목코드 | 품목명 | 거래처 | 24년 | 25년 | **26년** | 최근구매가 | 구매 | |

- **연도별 단가** — 큰 숫자가 계약단가, 아래 작은 글씨가 실제 발주
  - `3.24 93,500` 3월 24일에 93,500원에 삼 (계약가보다 비싸면 빨강, 싸면 파랑)
  - `8.11 발주` 계약단가가 없어서 큰 숫자 자체가 그날 산 값
  - `3.13 일치` 계약단가대로 삼
- **거래처** — 실제 납품한 회사. 여러 곳이면 `외 N`. 아래 계약방식 배지

## 구매 터미널 (`/dashboard/`)

| 패널 | 읽는 법 |
|---|---|
| 1) SPEND MONITOR | 월별 발주금액, 연도 겹쳐보기 |
| 2) ANNUAL | 연도별 금액·건수·품목수 |
| 3) CONTRACT MIX | 수의·입찰·사업비 비중 |
| 4) VENDORS | 거래처 금액 상위 20 |
| 5) PRICE UP | 전년 → 올해 오른 품목. **협상 1순위** |
| 6) PRICE DOWN | 내려간 품목 |
| **7) SAVINGS** | **최저가로 다 샀다면 아꼈을 금액** |
| 8) DEPARTMENTS | 요청부서 상위 14 |
| 9) OVER CONTRACT | 단가표보다 비싸게 산 것 |
| 10) SOLE SOURCE | 3회 이상인데 거래처 1곳 |
| 11) DATA INTEGRITY | 단가 × 수량 ≠ 금액 |

**7) SAVINGS** 가 제일 실용적입니다. `Σ (그때 산 단가 − 최저가) × 수량` 이라,
"이 품목 단가계약 걸면 연간 얼마"가 바로 나옵니다.

### 수치를 어떻게 믿을 만하게 만들었나

- **연도 대표단가는 중앙값**입니다. 마지막 값으로 잡으면 수량 누락 줄 하나에
  `8원 → 68,400원` 같은 헛수치가 나옵니다.
- 단가 × 수량 ≠ 금액인 줄이 하나라도 있는 품목은 **단가 변동 패널에서 뺍니다.**
- 변동률 200% 초과는 규격이 바뀐 것으로 보고 뺍니다.
- 전년 동기 대비는 **올해 마지막 달까지 잘라서** 비교합니다.

퍼킨엘머 Metal Consumables 29건 중 **22건에 FITI 품목코드가 없습니다.**

원본이 퍼킨엘머 본사 정가표(`P/N · Description · List price`)라 **품목코드 칸 자체가 없습니다.**
제품번호로 나무·인재시스텍 리스트와 대조해 7건은 찾았고, 나머지는

- 나무 2026 단가 리스트 — 없음
- 인재시스텍 2025 리스트 — 없음

즉 사본 적이 없어 코드가 만들어진 적 없는 품목입니다. 정가 합계 1억 1,172만원.

> 검색창이나 품목코드 열 필터에 **`미등록`** 을 넣으면 22건이 모입니다.

## 다시 만들기

원본 엑셀이 바뀌면 **`재생성.bat` 더블클릭** 한 번.

`단가검색-site/rebuild.sh` 로 데이터를 새로 뽑고, `배포판/` 을 통째로 다시 조립합니다.
원본은 `38.구매시스템_개발\10.통계파일` 과 `단가계약 대상` 을 봅니다.
열 순서가 바뀌면 멈추면서 알려줍니다.

**고친 값과 수정 이력은 지워지지 않습니다.** 원본 위에 수정분을 덧씌우는 구조입니다.

### 정합성 점검

`Dashboard-site/점검.bat` → **`이상치점검.tsv`** (엑셀로 열립니다)

| 사유 | 근거 |
|---|---|
| `금액불일치` | 단가 × 수량 ≠ 발주금액 |
| `수량1_고단가` | 수량 1인데 단가가 그 품목 중앙값의 5배 이상 |

중앙값은 수량 2개 이상인 줄만 써서 냅니다. 오염된 줄이 기준을 흔들지 않게.

## 배포

> **저장소는 반드시 Private.** 단가표와 발주 이력 전체가 들어 있습니다.
> Public 이면 Vercel 접근 제한을 걸어도 GitHub에서 그대로 읽힙니다.
> Settings → Danger Zone → Change repository visibility → **Make private**

GitHub 에는 **`배포판/` 안의 내용물**을 올리세요. 폴더 자체를 끌면 주소가 어긋납니다.

Vercel: Framework Preset **Other**, Build Command·Output Directory **비워둠**.

### 수정을 서버에 남기려면

Storage → **Create Database** → **Blob** → Create → Deployments 에서 **Redeploy**

안 하면 수정이 각자 브라우저에만 저장됩니다. 상단 배지로 확인:
`서버 저장 · 팀 공유`(녹색) / `이 브라우저에만 저장됨`(빨강)

점검: `/api/store` → `{"overrides":{},...}` 나오면 정상

### 접근 제한

Settings → Deployment Protection → **Vercel Authentication**
